# Clean Generic Portfolio

Static GitHub Pages portfolio using the content from the supplied site.

## Structure
- `index.html`
- `styles.css`
- `script.js`
- `data.json`

## Important
Projects are displayed in a responsive 3-column grid on desktop and 2/1 columns at smaller sizes. Each project has:
- embedded YouTube/Vimeo video
- title
- project metadata
- a direct "Open video ↗" link

Edit `data.json` to change the content without touching the layout.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the `main` branch, root folder.
